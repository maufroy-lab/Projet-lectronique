# 📚 Documentation technique

## Présentation

Cette branche regroupe la documentation technique associée au projet.

Elle décrit la démarche suivie depuis la définition du besoin jusqu'à la validation du prototype.

---

## 📁 Organisation

```text
docs/
├── README.md
├── cahier-des-charges.md
├── architecture.md
├── choix-techniques.md
├── conception.md
├── procedures-tests.md
└── bilan.md
```

---

## 📋 Cahier des charges

Le cahier des charges définit :

* le besoin ;
* les fonctions attendues ;
* les contraintes ;
* les interfaces ;
* les contraintes d'alimentation ;
* les critères de validation.

---

## 🧩 Architecture

Cette documentation présente :

* l'architecture matérielle ;
* l'architecture logicielle ;
* les interfaces entre les différents blocs ;
* le fonctionnement général du système.

---

## 🔎 Choix techniques

Les choix de conception sont justifiés à partir de :

* contraintes électriques ;
* caractéristiques des composants ;
* disponibilité ;
* coût ;
* encombrement ;
* performances attendues.

Les références aux datasheets seront conservées lorsque nécessaire.

---

## 🔧 Conception

Cette partie documente :

1. conception du schéma ;
2. choix des composants ;
3. conception du PCB ;
4. vérification ERC ;
5. vérification DRC ;
6. préparation de fabrication.

---

## 🧪 Procédures de test

Les procédures décrivent précisément :

* les conditions de test ;
* le matériel utilisé ;
* les points de mesure ;
* les valeurs attendues ;
* les critères de réussite.

Les résultats sont conservés dans la branche [`measurements`](https://github.com/maufroy-lab/Projet-lectronique/tree/measurements).

---

## 📊 Bilan

Le bilan final doit présenter :

* les fonctions validées ;
* les problèmes rencontrés ;
* les causes identifiées ;
* les corrections apportées ;
* les limites du prototype ;
* les améliorations possibles.

---

## 🎓 Objectif pédagogique

Cette documentation a également pour objectif de démontrer une démarche professionnelle :

**Analyser → Concevoir → Réaliser → Mesurer → Diagnostiquer → Corriger → Documenter**

Cette méthodologie constitue une partie importante du portfolio présenté dans le cadre de ma recherche d'alternance en **BTS CIEL option B — électronique et réseaux**.
