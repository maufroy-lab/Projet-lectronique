# 03 — Projet électronique

Projet de conception d'une carte électronique de commande et d'acquisition autour d'un microcontrôleur 3,3 V.

## Objectif

Concevoir un prototype reproductible comprenant alimentation, microcontrôleur, entrées analogiques, sorties de commande et interface de programmation.

## Périmètre

- alimentation d'entrée : 5 V ;
- logique : 3,3 V ;
- MCU : ESP32 ;
- acquisition : entrée analogique ;
- commande : sortie GPIO ;
- connectique : USB/UART et borniers ;
- conception PCB 2 couches.

## Livrables

- documentation de conception ;
- schéma de principe ;
- nomenclature ;
- base firmware ;
- stratégie de tests et mesures ;
- médias de référence.

> Le schéma et les médias fournis sont des supports de prototype/documentation. Une fabrication réelle nécessite une revue ERC/DRC et une validation électrique avant commande du PCB.
