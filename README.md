Pour conserver une documentation claire :

```text

04_pcb_bottom.png

06_alimentation.png
07_test_gpio.png
08_test_adc.png
09_uart.png
```

Les fichiers doivent être nommés de manière descriptive afin de faciliter leur utilisation dans la documentation principale.
